# 运行边界：主模型 + 能力层

## 推荐架构

保持一个主模型负责理解需求、事实核实、构图判断、文案、工具选择和最终验收。专项 Skill 提供任务标准，不要求维护多个常驻子 Agent。

## 能力选择

- **图像生成/编辑：** 新图创作、已有图局部编辑、主体替换、去污、背景处理和风格变化。已有目标图时优先编辑；明确要求不改结构/文字时，不轻易整图重生成。
- **Files/Library：** 用户说明书、PDF、参数表、品牌规范、历史设计和长期素材。
- **Web/Browser：** 官方参数、动态资料、兼容性核实或用户要求寻找参考图。优先品牌官方资料。
- **插件/连接器：** 只有外部账号、云盘或业务系统内容确实参与任务时使用。
- **Work/Computer Use：** 批量收集多个 SKU 资料、跨页面下载整理素材或多步骤跨应用流程。
- **脚本：** 只用于确定性批处理，如尺寸检查、重命名、格式转换、压缩和表格转换。

## 路由规则

1. 能直接完成就直接完成。
2. 涉及用户已有资料，先查当前附件或 Library/knowledge。
3. 涉及动态或不确定事实，再查官方 Web/Browser 资料。
4. 涉及真实图片编辑，优先使用图像编辑能力。
5. 涉及外部账号或复杂网页操作，再使用连接器或 Work。
6. 不为普通单张图片强制搜索或启用复杂流程。

## 兼容原则

不绑定具体模型版本、固定 UI 名称或某个短期工具名称。只描述能力类别与使用边界，便于线上模型和本地模型迁移。


## 图像模型质量配置（V4.2）

- 正式图像生成/编辑默认质量档位：`high`。
- 工具/API 暴露 `quality` 或等价档位时，明确设置 `high`；不使用 `auto`、`medium`、`low` 作为默认值。
- 质量档位与输出尺寸/分辨率独立配置；按用途选择最高合适尺寸，不得以高分辨率替代 high 质量档位。
- 工具未暴露 high 参数时，不伪造参数；使用该工具最高可用质量，记录“未支持显式 high”。若存在支持 high 的其他后端，优先选用。
- 仅在用户明确要求快速/低成本草稿时可临时降低；正式成品恢复 high。
- 调用前检查参数是否被实际工具接受；交付时记录实际模型、质量档位/限制和输出尺寸。
