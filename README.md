# 美工 Skills V4.2

本包包含 1 个美工总控 Skill 和 6 个专项 Skill。V4.2 在 V4.1 基础上增加自由排版、文案与视觉素材强绑定、多页详情连续叙事、实拍素材硬锁定，以及图像模型质量默认 high。

## 目录

- `meigong/`：美工总控，负责任务识别、5S+R、专项路由、统一事实保护、模型质量和交付验收。
- `meigong-product-retouch/`：白底精修、去污、去黑影、材质净化。
- `meigong-main-image/`：电商主图设计。
- `meigong-detail-page/`：详情页、尺寸图、参数图和应用案例；重点执行图文强绑定与多页连续叙事。
- `meigong-sku-card/`：SKU 型号与参数信息卡。
- `meigong-photo-replacement/`：实拍替换、局部修改和主体更换；重点执行实拍结构锁定。
- `meigong-technical-visual/`：结构示意、工作原理、技术说明和应用场景图。

## V4.2 新增全局规则

1. **排版自由：** 不设固定网格、左右布局、标题位置、图片数量或页面模板；根据内容和素材设计。
2. **图文绑定：** 每条标题、卖点、说明和参数都必须对应具体视觉素材/局部或可核验事实。
3. **多页承接：** 详情页先规划整套叙事，上下页有延续、解释或证明关系，不输出孤立图片集合。
4. **实拍锁定：** 产品结构、比例、接口、零件、标签、刻字、材质和工作逻辑不得被模型擅自改变。
5. **质量 high：** 正式图像生成/编辑默认使用 `quality=high`；工具不支持显式 high 时，使用最高可用质量并说明限制，不得默默降档。

## 安装建议

1. 用 `meigong/` 总控 Skill。
2. 将其余 6 个目录分别作为独立 Skill 导入。
3. 总控负责判断任务；明确的专项任务由对应专项 Skill 执行。若某个专项未被单独加载，也可按总控中的对应标准完成。
4. 不要把本包中的 7 个目录合并成一个 Skill；每个目录都是独立的 Skill 包。

## 继承规则

- 保留 V4.1 的 5S+R、产品事实优先级、最小差异编辑、专项路由和交付 QA。
- 系列统一的是视觉语言，不是固定构图模板。
- 用户最新确认的实拍素材优先；产品本体优先用像素保留式处理。
- 白底产品整体清洁归白底精修；指定区域编辑、主体替换归实拍替换。
- 不确定的技术事实先核实，不猜测、不编造。
- 默认交付独立图片；比例、张数和格式以用户要求为准。
